# Royston Stewart P — Premium Portfolio

A static HTML, CSS and JavaScript portfolio designed for VS Code + Live Server.

## Run locally
1. Extract this folder.
2. Open `ROYSTON_PREMIUM_PORTFOLIO` in Visual Studio Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.

## Folder guide
- `index.html` — portfolio homepage
- `projects/` — individual project detail pages
- `css/style.css` — responsive Forest Green + Ivory styling
- `js/script.js` — navigation, scroll progress and reveal effects
- `assets/images/profile.jpg` — supplied profile photo (unchanged)
- `assets/certificates/` — supplied internship certificate images
- `assets/resume/` — supplied resume document

## Before publishing
- Check the phone number, email, LinkedIn and GitHub links.
- Add a certificate for Brainery Software Technologies if you have one.
- Add project reports, circuit diagrams, GitHub repository links or demo videos to strengthen each case study.
- The portfolio uses a short lyric excerpt, “A sky full of stars.” — Coldplay.
- External Google Fonts require an internet connection; system fallbacks are included.

All project descriptions are based on the supplied résumé. Where detailed circuit or implementation information was not provided, the case studies avoid inventing technical specifics.
